# Offline cl100k_base encoding

Source: https://openaipublic.blob.core.windows.net/encodings/cl100k_base.tiktoken

SHA-256: `223921b76ee99bde995b7ff738513eef100fb51d18c93597a113bcffe865b2a7`

The encoding table is bundled so tokenizer initialization does not download data.
The regex and special-token definitions match tiktoken 0.12.0 `tiktoken_ext.openai_public.cl100k_base`.
Changing this table or tokenizer requires rebuilding document chunks.
