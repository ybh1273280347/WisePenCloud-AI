# 原生文件编写计划索引

本目录存放“原生文件编写”相关规划文档。

这组计划的目标不是做单个格式转换器，而是规划一套统一文件编写能力：

- 直接写文件，而不是先转中间格式再降级输出
- 对有成熟校验链路的格式执行结构/渲染/视觉校验
- 允许在沙箱中直接写代码生成文件
- 支持文件产物独立交付，也支持嵌入到 DOCX 等文档中
